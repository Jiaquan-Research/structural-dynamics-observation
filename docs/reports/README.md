# Reports

This directory contains report-oriented materials related to the structural dynamics observation framework.

Primary report themes:

* Structural Dynamics Taxonomy: summarizes pair-space regimes such as diffuse wandering, metastable basins, and single-edge attractors.
* Research Audit Package: defines the adversarial review boundary, assumptions, and methodological risks.
* Marine Mapping: maps the current industrial proof-of-mechanism work toward future marine engine-room validation targets.
