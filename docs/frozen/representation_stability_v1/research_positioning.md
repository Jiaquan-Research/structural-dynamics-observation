# Research Positioning

## What This Project Is

This project is currently a representation-level detector family study.

It focuses on:

- detector disagreement
- representation stability
- subspace statistical structure
- fault-conditioned geometry behavior
- empirical taxonomy of representation-space patterns

The central question is not which detector is universally best.
The central question is what statistical structure each detector observes.

## What This Project Is Not

This project is not:

- a fault diagnosis product
- a causal discovery engine
- a physical simulation
- proof of attractor dynamics
- proof of physical locking
- evidence for process ontology

## Current Interpretation Boundary

Terms such as locked, stable, diffuse, geometry concentration, and pair persistence are descriptive labels for representation-space statistics.

They do not establish physical causality, physical attractors, or control-theoretic stability.

## Why Freeze This Snapshot

This snapshot freezes the descriptive baseline before Transfer Entropy exploration. That protects the project from retroactively upgrading descriptive classes into mechanism claims.
