# 一、工作目标变化

本轮工作的核心变化：

从：

```text id="68h0k5"
“geometry detector 是否能够作为通用 fault detector”
```

转向：

```text id="14xpwq"

```


## 5.2 核心发现：稳定 geometry-sensitive family

在：

```text id="2r9t4q"
threshold = 0.65 → 0.85
```

整个区间内：

```text id="5f4jhn"

```

而：

```text id="w5z4lq"

```

说明：

```text id="c5p83j"
geometry sensitivity
是 fault-specific
而不是通用性质
```

---

## 5.3 Threshold cliff

发现：

```text id="r5p2cq"
0.85 → 0.90
```

之间存在 signal collapse：

```text id="t8mf7z"
F06/F08/F14 detection 突然坍塌
```

说明：

```text id="q6y8ya"
geometry dominance
集中在有限幅值区间
```

---

## 5.4 FP floor

发现：

```text id="hrbg3h"
threshold = 0.90
threshold = 0.95
```

时：

```text id="0g6z3h"
FP 均为 2.51%
```

说明：

```text id="r5fgv8"
存在 irreducible FP floor
```

即：

```text id="mdtqwb"
NORMAL 中存在天然高-concentration windows
```

因此：

```text id="8rxt4v"
top1_mass 是 fault-sensitive
但不是 fault-exclusive
```

# 九、本轮最重要结论

当前结果支持：

```text id="h7v5k5"
top1_mass
不是 universal detector
不是 classical propagation detector
```

更准确定位为：

```text id="0p8a2n"
fault-specific geometry locking detector
```

并且：

```text id="p0m1vj"
它对特定 fault family
（F06/F08/F14）
具有极强结构敏感性
```

但：

```text id="k6d5mt"
不具备通用 fault coverage
```

这是截至 2026.05.13 当前阶段最准确的系统定位。
